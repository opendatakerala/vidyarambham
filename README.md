# ഡിജിറ്റൽ വിദ്യാരംഭം · Digital Vidyarambham

ഡിജിറ്റൽ ആയി ആദ്യാക്ഷരം കുറിയ്ക്കാം — a bilingual (Malayalam / English) web portal where a child traces
ഹരി ശ്രീ ഗണപതയേ നമഃ, the 15 vowels and the 36 consonants in a tray of rice or sand, and receives a PNG certificate.
